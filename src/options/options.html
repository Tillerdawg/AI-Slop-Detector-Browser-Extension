Sensitivity

How aggressively to flag videos. This only changes the score cutoffs, not what's measured.

Upload-cadence signal

This is one of the strongest signals (content-mill channels often post many videos a day) but requires an extra network request per new channel encountered. Results are cached for 24 hours per channel, and requests are throttled, to keep this light. Uses YouTube's public RSS feed by default, or the Data API below if you supply a key.

Optional: YouTube Data API key

Without a key, upload cadence comes from YouTube's public RSS feed (works out of the box, no signup). Adding a free Data API v3 key gives more reliable channel age / total-upload-count data too, at a fraction of the free daily quota. The key is stored only in your browser and only ever sent to googleapis.com.

Video overrides

Videos you've manually marked as trusted (human-made) or flagged (AI slop), from the ✅/🚩 buttons on the watch-page panel. These always take priority over the heuristic score.

    Community ratings

    Optionally layer in crowd-sourced votes (SponsorBlock-style) on top of the local heuristic, backed by a small hosted service you (or someone you trust) runs. Set a backend URL and you can vote directly from the watch-page panel — there's no sign-in or verification step. Leave the URL blank to keep everything fully local.

    Privacy

    Scoring runs locally in your browser. The only network requests this extension makes are: direct GET requests to youtube.com/feeds/videos.xml for upload cadence; — only if you add a key above — to googleapis.com; and — only if you fill in a Backend URL under “Community ratings” above — to that backend, a server you typed in yourself. That last one is the only case in which anything about what you're watching leaves your browser: it gets the video ID of the video you're on, to look up and record votes for it, plus a random per-install ID that isn't tied to your account, name, or any other identity. Leave the Backend URL blank and none of that happens. No usage data, browsing history, or telemetry is sent anywhere.
